# Rafael Transporte Foz

Site estático (HTML/CSS/JS) + painel admin + Supabase. Publicado no Netlify.

- Guia completo: `GUIA-IMPLANTACAO.md`
- Banco: rode `supabase-instalacao.sql` e depois `supabase-blindagem.sql` no SQL Editor do Supabase
- Configuração do cliente: `site-config.js` (modelo em `site-config.modelo.js`)
- Segurança: `_headers` (CSP em modo Report-Only; veja o guia para ativar)

Nunca coloque chave `secret`/`service_role` neste repositório.
